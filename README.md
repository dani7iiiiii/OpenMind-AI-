# OpenMind-AI-
An open-source AI assistant with memory, document chat, web search, customizable personalities, and support for multiple AI models (OpenAI, Anthropic, Google Gemini, Ollama) Features  * 💬 AI Chat * 🧠 Long-term memory * 📄 Chat with PDFs * 🌐 Web search * 🤖 Multiple AI providers * 📝 Conversation history * 🎨 Modern UI * 🔌 Plugin support
